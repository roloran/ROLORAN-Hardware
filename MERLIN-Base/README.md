# MERLIN Base

The MERLIN-Base is a dual-purpose installation. Its primary function is to function as stations forming the wireless backbone network. Its secondary function is to serve as a user interface for transmitting/receiving messages.

The following files are contained:
- _Elec_Components_Case.FCstd_: A FreeCAD file containing a model of the case for storing electrical components inside the MERLIN-Base.
  This case is an enclosure for the `LoRaQuadV2` circuit board and comes with holes for all required external connections.
  If printed measures should be taken to get it as waterproof as possible. 
- _Elec_Components_Case_Simplified.FCstd_: A variant of _Elec_Components_Case.FCstd_ with simplified geometry.
  This variant also contains a drilling template.
- _Elec_Components_Case_Cover.FCstd_: Cover for the the _Elec_Components_Case.FCstd_.
- _MERLIN-Base-Inlay.stl_: PCB mounting insert with cable management
- _MERLIN-Base-PCB-Holder.stl_: Key to insert into the _MERLIN-Base-Inlay.stl_ to hold the PCB in place
