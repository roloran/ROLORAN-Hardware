# RDCP-Modem

The RDCP-Modem is a RDCP-compatible component, used by MERLIN network parties such as the crisis management team or the big red emergency button to communicate with the MERLIN system. For a relay setup based on the `LoRaQuadV2` board, this case combines a base, back panel, and body.

- _RDCP-Modem-Base.stl_: Base plate the _RDCP-Modem-Case.stl_ can be mounted on, stabilizing the PCB
- _RDCP-Modem-Case.stl_: Case which holds the `LoRaQuadV2` PCB at its SMA sockets
- _RDCP-Modem-Back-Panel.stl_: Back plate which closes off the enclosure with a sliding mechanismn
